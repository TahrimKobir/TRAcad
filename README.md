# Assignment Cover Generator

A free, responsive academic assignment cover generator built with plain HTML, CSS and JavaScript.

## Features

- Live A4 cover preview
- Multiple templates, including an SAU-style assignment template
- Student / course / teacher information
- Institution logo upload
- Local browser storage
- Print-ready A4 layout
- Direct PDF download
- Responsive mobile UI
- No backend or database required
- GitHub Pages compatible

## Run locally

Just open `index.html` in a browser.

For the best experience, use VS Code Live Server or any simple local web server.

## Deploy to GitHub Pages

1. Create a new GitHub repository.
2. Upload `index.html`, `style.css`, `script.js`, and the `assets` folder.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select your main branch and `/ (root)`.
6. Save.
7. GitHub will provide your free `github.io` website address.

## Important

PDF generation uses the `html2pdf.js` library from cdnjs. If the CDN is unavailable, the Print button can still be used to save the cover as PDF.
